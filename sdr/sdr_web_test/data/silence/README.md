# Файл заглушки для временной шкалы

## Назначение
Файл `nothing.iq` используется для заполнения пробелов между записями спутников на временной шкале.

## Требования к файлу
- **Формат**: Raw IQ данные (complex64)
- **Частота дискретизации**: 625000 Гц (625 кГц)
- **Центральная частота**: 433.000 МГц (будет отображаться как 433.060 МГц на спектре)
- **Длительность**: 5 минут (300 секунд)
- **Размер файла**: ~1.5 ГБ (625000 * 300 * 8 байт)

## Как создать файл заглушки

### Вариант 1: Запись через GNU Radio
1. Настройте GNU Radio на частоту 433.000 МГц
2. Установите sample rate 625000
3. Запишите 5 минут "тишины" (без активных сигналов)
4. Сохраните как `nothing.iq`

### Вариант 2: Генерация программно
```python
import numpy as np

# Параметры
sample_rate = 625000  # 625 кГц
duration_seconds = 300  # 5 минут
total_samples = sample_rate * duration_seconds

# Генерируем слабый шум (имитация фона приемника)
noise_level = 0.001
samples = (np.random.randn(total_samples) + 1j * np.random.randn(total_samples)) * noise_level

# Сохраняем как complex64
samples = samples.astype(np.complex64)
with open('nothing.iq', 'wb') as f:
    f.write(samples.tobytes())
```

## Как работает заглушка
1. При воспроизведении временной шкалы система автоматически определяет пробелы между записями
2. В пробелах воспроизводится файл `nothing.iq` (зацикленно)
3. **Автоматический ресэмплинг**: Файл записан на 625 кГц, но автоматически преобразуется в 312.5 кГц для совместимости
4. На спектрограмме отображается частота последнего пролета (433.060 МГц)
5. Создается впечатление непрерывной работы приемника
