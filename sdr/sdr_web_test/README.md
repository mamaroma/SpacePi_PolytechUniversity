# SDR Трансляция

Веб-приложение для потоковой передачи и анализа SDR данных с автоматическим отображением информации о спутниках.

## Новая концепция

### Данные спутников
- Характеристики сигналов спутников хранятся на сервере в файле `app/sdr/satellites.json`
- Центральная частота всегда равна частоте спутника + 60 кГц
- Частота дискретизации всегда 312.5 кГц
- Информация о ближайшем пролете автоматически определяет отображаемые параметры сигнала

### Архитектура
- **Спутниковые данные**: Хранятся локально в JSON файле
- **Пролеты**: Отправляются через API из внешних источников
- **Параметры спектра**: Отправляются отдельно для управления FFT
- **Интерфейс**: Автоматически показывает данные ближайшего спутника


#### Отправка пролетов из JSON файла:
```bash

python send_passes.py orbits.json
```

#### Отправка параметров спектра:
```bash
cd tracking
python send_spectrum_params.py 436550000 1024 30
```

#### Тестирование новой концепции:
```bash
cd tracking
python test_new_concept.py
```

## API Endpoints

### Спутники
- `GET /api/satellites` - Получить все данные спутников
- `GET /api/satellites/{name}` - Получить данные конкретного спутника

### Пролеты
- `POST /api/passes` - Отправить список пролетов
- `GET /api/passes` - Получить все пролеты
- `GET /api/passes/next` - Получить ближайший пролет

### Спектр
- `POST /api/spectrum/params` - Отправить параметры спектра
- `GET /api/signal/info` - Получить объединенную информацию (спутник + спектр)

### Запись
- `POST /api/record/start` - Начать запись IQ данных
- `POST /api/record/stop` - Остановить запись
- `GET /api/record/state` - Состояние записи

## GNU Radio интеграция

### Рабочий блок-источник
Используйте `gnuradio_source_block.py` для автоматической отправки метаданных:

```python
# В GNU Radio Companion добавьте Python Block
# Укажите путь к файлу: gnuradio_source_block.py
# Параметры:
# - center_frequency: частота спутника (Гц)
# - sample_rate: 312500 (фиксированная)
# - satellite_name: название спутника
```

Блок автоматически:
- Отправляет параметры сигнала при запуске графа
- Создает прогноз пролета
- Поддерживает работу графа генерацией нулевых данных

## Использование

1. **Запустите сервер**: `python run.py`
2. **Откройте браузер**: http://localhost:8000
3. **Отправьте пролеты**: `python tracking/send_passes.py tracking/orbits.json`
4. **Настройте спектр**: `python tracking/send_spectrum_params.py 436550000`
5. **Проверьте интерфейс**: Информация о ближайшем спутнике отобразится автоматически

## Особенности

- **Автоматическое определение спутника**: Система показывает данные ближайшего пролета
- **Фиксированные параметры**: Центральная частота = спутник + 60 кГц, дискретизация = 312.5 кГц
- **Минималистичный дизайн**: Темная тема, зеленые акценты
- **Русский интерфейс**: Все элементы на русском языке
- **WebSocket спектрограмма**: Реальное время отображения спектра
- **Запись IQ данных**: Сохранение в файлы .iq

## Технологии

- **Backend**: FastAPI, Python 3.8+
- **Frontend**: Vanilla JavaScript, HTML5 Canvas
- **WebSocket**: Потоковая передача FFT данных
- **GNU Radio**: Интеграция через Python блоки
- **Форматы данных**: JSON, IQ файлы
