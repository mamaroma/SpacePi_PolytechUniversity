# Отборочное задание Artek (AIS)

Этот файл дополняет `Konkurs.docx` и фиксирует формат отборочного этапа.

## Базовый сценарий

1. Запустить генератор `main.py` и выбрать один из уровней (1-4).
2. Получить входные пакеты `input_levelX.csv`.
3. Декодировать данные участником и сформировать свой CSV-ответ.
4. Проверить решение через `competition_runner.py`.

## Дополнительные задания

1. **Собственный декодер**  
   Участник может добавить файл `participant_decoder.py`.
   - Точка входа: функция `decode_packets(rows)`.
   - `rows` — список словарей с полями `timestamp`, `ais_sentence`.
   - Возврат: список словарей (`mmsi`, `lat`, `lon`, `speed`, `last_seen`).

2. **Собственная визуализация**  
   Участник может добавить файл `map.py`.
   - Визуализация должна строиться только по данным участника.
   - Файл может читаться и запускаться проверяющими отдельно.

## Требования к упаковке решения

- Базовое решение должно запускаться **из коробки** без PyQt.
- Дополнительные зависимости допустимы только в допзаданиях.
- Рекомендуемый состав:
  - `participant_decoder.py` (если есть),
  - `participant_output.csv`,
  - `map.py` (если есть),
  - сопроводительный `README.md`.

## Разделение инструментов

- `competition_runner.py` — рабочий цикл генерации/проверки.
- `ais_map.py` — инструмент для проверяющих (сравнение эталона и ответа).
- Участнику не выдаётся готовый эталонный CSV для прямого копирования.
