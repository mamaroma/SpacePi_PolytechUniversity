Main.py -- Генератор пакетов, внешних библиотек не нужно.
1 уровень- генерирует пакеты реальных кораблей, с шансом 20 % выдаёт ошибку в в координатах\скорости
2 уровень - взят рандомный mmsi, просто согласно точкам генерирует пакеты
3 Уровень - генерирует несколько судов по обе стороны панамского канала
4 Уровень создаёт 4судна, идут линейно, в определённом радиусе от заданной точки координаты начинают "шуметь"


ais_map.py - отображает пакеты на карте. Если навестись курсором на точку, покажет mmsi и скорость.

требует библиотек plotly, pyqt5, PyQtWebEngine (pip install PyQt5 PyQtWebEngine plotly)
