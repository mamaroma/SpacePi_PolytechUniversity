# Описание задания: анализ AIS-телеметрии

## 1. Цель

Разработать программный модуль для автоматического **анализа, валидации и фильтрации** данных AIS (Automatic Identification System).

## 2. Контекст

Современное судоходство зависит от GNSS/GPS и AIS. Береговые службы используют AIS для контроля трафика и предотвращения столкновений.

Система уязвима к:
- **аппаратным сбоям и помехам** — битые пакеты, невозможные координаты;
- **GPS-спуфингу** — подмена координат в зоне атаки при сохранении правдоподобной скорости и курса.

Вам даны логи перехвата эфира в четырёх зонах. Нужно очистить данные и выявить аномалии.

## 3. Что предоставляет организатор

| Компонент | Назначение |
|-----------|------------|
| `main.py` | Генератор сырых пакетов `input_levelN.csv` |
| `ais_core/` | Ядро симулятора |
| `decoder.py.example`, `map.py.example` | Шаблоны интерфейсов (не готовое решение) |
| `participant_map.py` | Вспомогательная самопроверка карты |
| `run_decoder.py` | Отладка `decoder.py` (не зачётное решение) |

## 4. Что реализует участник (обязательно)

| Компонент | Описание |
|-----------|----------|
| **Парсер / декодер** | Разбор NMEA, декодирование 6-bit payload, извлечение MMSI, lat, lon, speed |
| **Фильтрация** | По правилам уровня (брак, выбросы, спуфинг) |
| **Экспорт** | `AIS_sim/output_levelN.csv` и доп. файлы |
| **Визуализация** | Своя карта (уровни 2 и 4 — обязательно) |

> Платформа **не содержит** готового решения. `run_decoder.py` и встроенная карта — только для проверки, что окружение работает.

## 5. Уровни и баллы (макс. 120)

| Ур. | Зона | Баллы | Суть |
|-----|------|-------|------|
| 1 | Финский залив | 15 | Валидация, MMSI + name + type |
| 2 | Порт Приморск | 25 | Трек без «прыжков» + карта |
| 3 | Панамский канал | 40 | Срез трафика + диспетчерские маршруты |
| 4 | Балтика | 40 | Антиспуфинг + зона + карта |

Оценка пропорциональна совпадению с эталоном (эталон участнику не выдаётся).

## 6. Язык и среда разработки

| Параметр | Рекомендация |
|----------|--------------|
| Язык | **Python 3** (предпочтительно), допустимы C++, Java и др. |
| Версия Python | 3.10+ |
| IDE | VS Code, PyCharm, любая |
| Библиотеки генератора | Не нужны (только stdlib) |
| Библиотеки для решения | На усмотрение участника (pandas, numpy и т.д.) |

(собирается кнопкой в `main.py`, Шаг 4).
