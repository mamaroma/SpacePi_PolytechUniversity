## 2. Среда разработки

- **Язык:** Python 3.10+ (рекомендуется 3.11)
- **ОС:** Windows 10/11, Linux, macOS
- **Базовые шаги 1–2:** только стандартная библиотека Python
- **Шаг 3 (карта):** браузер + интернет для подложки OpenStreetMap (без PyQt)

### macOS

```bash
cd AIS_sim
python3 main.py --level 2 --step generate
python3 main.py --level 2 --step decode
python3 main.py --level 2 --step map
```

Если `python3` не найден: установите Python с https://www.python.org/downloads/  
GUI (`python3 main.py` без аргументов) на Mac работает, если установлен tkinter (обычно есть в официальном Python).

### Дополнительные библиотеки (только если делаете своё расширенное решение)

| Задача | Библиотеки |
|--------|------------|
| Свой декодер | только stdlib или `pyais` (опционально) |
| Своя карта (шаблон) | stdlib + браузер |
| Расширенная визуализация | `matplotlib`, `folium`, `plotly` — по желанию |

## 3. Рабочая папка и имена файлов

Все файлы участника лежат в **одной папке `AIS_sim/`** (рядом с `main.py`):

| Файл | Кто создаёт |
|------|-------------|
| `input_level1.csv` … `input_level4.csv` | Шаг 1 |
| `participant_decoder.py` | Участник (из шаблона) |
| `output_level1.csv` … `output_level4.csv` | Шаг 2 |
| `participant_map.py` | Участник (из `participant_map_template.py`) |

**Важно:** файл карты должен называться именно **`participant_map.py`**, не `map.py`.  
`main.py` ищет его в папке `AIS_sim/`.

## 4. Пошаговый алгоритм

### Шаг 1 — получить входные данные

**GUI:** кнопка «Шаг 1 — сгенерировать input»  
**CLI:**

```bash
python main.py --level N --step generate
```

Результат: `input_levelN.csv` (колонки `timestamp`, `ais_sentence`).  
Эталон **не создаётся** — участник не может подсмотреть правильный ответ.

В потоке есть повреждённые пакеты (уровень 1: ~20% ошибок в данных, ~5% битых строк).

### Шаг 2 — декодирование

1. Скопируйте `participant_decoder_template.py` → `participant_decoder.py`
2. Реализуйте функцию `decode_packets(rows)`
3. Запустите:

```bash
python main.py --level N --step decode
```

**GUI:** кнопка «Шаг 2 — декодировать»

Программа сообщит:
- сколько строк входа прочитано;
- сколько пакетов успешно декодировано;
- сколько уникальных MMSI в ответе;
- куда сохранён `output_levelN.csv`.

Участник **не видит эталон**. Сообщение «найдено 34 строки» означает, что декодер отработал и записал результат; правильность оценивает проверяющий или портал.

### Шаг 3 — карта (уровни 2–4)

1. Скопируйте `participant_map_template.py` → **`participant_map.py`**
2. Выполните шаг 2 (должен быть `output_levelN.csv`)
3. Запустите:

```bash
python main.py --level N --step map
```

или напрямую:

```bash
python participant_map.py --csv output_level4.csv
```

Откроется HTML-карта **только ваших** точек в браузере.

## 7. Уровни — кратко

| Уровень | Зона | Формат ответа |
|---------|------|----------------|
| 1 | Финский залив | `mmsi`, опционально `name`, `type` |
| 2 | Порт Приморск | `mmsi, lat, lon, speed, last_seen` + карта |
| 3 | Панамский канал | 13 судов в двух кластерах |
| 4 | Балтика | 4 параллельных трека, зона спуфинга |

Уровень 3: 7 судов у подхода с Атлантики, 6 — со стороны Тихого океана.  
Уровень 4: 4 судна с MMSI 273111000…273444000 идут параллельными коридорами на восток; в зоне спуфинга координаты искажаются.
